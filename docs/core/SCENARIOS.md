## Как реализуется сценарий

Один сценарий — один файл `tests/scenarios/<код>.test.ts`. Внутри: подготовка эмулятора (`setup`), действие агента, проверка ожидаемого результата и **проверка отсутствия обхода**: в журнале испытаний нет запрещённых событий (повтор без устранения причины, обращение без подписи, вызов контура без проверки `policy`). Команда `/scenario <код>` ведёт по этому порядку.
