## Следующая сессия

**Сессия 1 · этап 1 «Фундамент контура» · около 3 часов**

Команда в терминале:

```
cd ~/repos/agentic-buyer-ref && claude
```

Затем в Claude Code: `/start`

Задачи сессии:

1. **Каркас кода.** Структура `src/` по `CLAUDE.md`, ESLint, сборка `tsc`, скрипты `npm test` и `npm run check`. Проверить, что `tests/scenarios/catalog.test.ts` зелёный.
2. **Общие типы.** `src/shared/`: типы из `docs/core/protocol/agent-protocol.v1.0.0.yaml` (ПАО) и из `openapi.yaml` мока, перечень кодов с HTTP-статусами и полем `retry`, загрузка `config/params.stand.json` со схемой zod.
3. **Подписант и К1.** `src/agent/signer` (ed25519, подпись `@method @path x-timestamp content-digest x-agent-code`), проверка подписи в эмуляторе, К1 реестр в памяти. Тесты П01, П02, П03.

Контрольные точки:
- после задачи 1 — показать дерево и вывод `npm test`;
- после задачи 2 — показать перечень типов и кодов, сверить с `openapi.yaml`;
- после задачи 3 — прогон П01–П03, коммит по команде владельца.

Готовые сообщения:
- `/task Т-01 Каркас кода и проверка каталога сценариев`
- `/task Т-02 Общие типы, коды отказа, конфигурация`
- `/task Т-03 Подписант ed25519 и К1 реестр; П01–П03`

За владельцем: создать репозиторий на GitHub, подтвердить Р1–Р13 (или назвать, что изменить), после сессии — PR из `claude-setup` в `main`.
