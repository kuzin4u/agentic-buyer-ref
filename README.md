# agentic-buyer-ref

Эталонный агент покупателя для агентной коммерции и эмулятор испытательного контура К1–К8.

Агент проверяет, исполнимы ли нормы A1–A9 (признак агентной операции, реестр агентов, ограничения в инструменте, ответственность, мандаты) на 30 сценариях приёмки. Работает в двух профилях: против испытательного контура (`/v1`) и против Agent Service маркетплейса (ст. 14–21, эскроу НСВР).
