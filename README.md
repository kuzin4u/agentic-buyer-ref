# agentic-buyer-ref

Детерминированное ядро агента покупателя для агентной коммерции и набор соответствия из 30 сценариев. Контур для проверки — Платформа ПС по ПАО v1 (`PaoStub`, стенд и песочница Платформы, эмулятор продавцов — Р26).

Агент проверяет, исполнимы ли нормы A1–A9 (признак агентной операции, реестр агентов, ограничения в инструменте, ответственность, мандаты) на 30 сценариях приёмки. Работает в двух профилях: против Платформы платёжной системы по ПАО v1 и против Agent Service маркетплейса (ст. 14–21, эскроу НСВР).
