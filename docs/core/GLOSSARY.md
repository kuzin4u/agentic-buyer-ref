# Термины

Полный словарь пула (96 терминов) — `docs/reference/pul/25-glossariy.html`. Здесь — термины, которые встречаются в коде.

| Термин | Значение | В коде |
|---|---|---|
| Агент | Программа, действующая по поручению клиента в пределах мандата | `Agent` |
| Оператор агента | Юрлицо, отвечающее за агента; включается в реестр | `Agent.operator` |
| Принципал | Клиент, выдавший мандат; в праве — представляемый | `principal_ref` |
| Код агента | «выдавшая сторона : идентификатор : версия», неизменен | `agent_code` |
| Уровень допуска | Объём прав агента, в том числе необходимость подтверждения | `Agent.level` |
| Мандат намерения | Задача и пределы: предмет, сумма, срок, получатели | `MandateType.INTENT` |
| Мандат корзины | Согласованные состав и стоимость со ссылкой на мандат намерения | `MandateType.CART` |
| Мандат платежа | Разрешение на списание при действующем мандате корзины | `MandateType.PAYMENT` |
| Журнал согласий | Неизменяемое хранилище мандатов с хэш-цепочкой | К2 |
| Пределы мандата | Содержание мандата на момент операции | `scope` |
| Ограничения без состояния | Проверяются по одной операции: сумма, получатель, категория, срок | `stateless` |
| Ограничения с состоянием | Требуют истории: бюджет за период, частота, одноразовость | `stateful` |
| Ограничения полномочий | Лимиты в платёжном инструменте | `Limits` |
| Признак агентной операции | Указание + код агента + id мандата | `aoi` |
| Запись об исполнении | Итог операции и результат сопоставления с пределами; формирует участник | `FulfilmentRecord` |
| Заказ | Единица исполнения; может включать несколько платёжных событий | `Order` |
| Немедленный режим | Клиент участвует в согласовании итоговых значений | `IMMEDIATE` |
| Автономный режим | Клиент задал пределы заранее | `AUTONOMOUS` |
| Удержание заказа | Ожидание подтверждения: ограничено по времени, однократно | `Order.status = HELD` |
| Контур гарантий | Продавцы, работающие по правилам Системы, со знаком готовности | `zone = CONTOUR` |
| Знак готовности | Отметка соответствия продавца требованиям A5; не влияет на выдачу | `readiness_mark` |
| Дробление | Разбиение суммы на части ради обхода порога подтверждения | событие `SPLIT_DETECTED` |
| Оценка исполнения | Показатели поведения агента; влияет на уровень допуска | `RunReport.metrics` |
| Обход нормы | Прохождение сценария в обход правила; считается провалом | `case.bypass = true` |
| Эскроу НСВР | Удержание средств до подтверждения получения (профиль platform) | `settlement_mode = escrow` |
